● Yes — for an ARPG with persistent characters you'll want: a title scene
  listing save slots with New/Load/Delete, a save file per character (e.g.
  user://saves/<name>.json) holding level/xp/gold, inventory items + affixes,
  equipment, allocated passives + unspent points, bosses defeated, and current
  zone, plus autosave on zone transition and quit.

  Recommendation: go with JSON via FileAccess rather than Godot
  Resource/ResourceSaver. Tradeoff — JSON is forgiving when we add new affixes,
  passive nodes, or zones (just default missing fields); Resource is type-safe
  but breaks old saves every time we change a class, which will happen
  constantly while the systems are still young. Each data class (Item,
  Inventory, Equipment, Passives) gets a to_dict/from_dict pair.

  If you want, I can start by adding SaveGame (serialization), then a
  TitleScreen scene that boots first, then hook autosave into zone transitions —
   say the word and I'll scaffold it.
